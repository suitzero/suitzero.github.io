Research

  • Anytime VM

    A minimal compute model with exactly three primitives: VALUE, REFINE, COMPOSE. Computation is the act of reducing uncertainty — every program is estimate → refine → refine → …, and any nonzero resources always yield a result. The VM knows nothing about CPUs, GPUs, or networks; hardware (GPUs today, photonics tomorrow) implements the VM's contract, not the other way around.

    View on GitHub

  • GFL — a budget-aware scene language

    A small SDF scene language with an anytime renderer: drag a budget slider and watch the same scene refine from coarse to fine, with the error-vs-budget tradeoff measured rather than mystical. The first visual demo of the Anytime VM ideas — inverse program synthesis included.

    View on GitHub
